LAMUEL REYES PORTFOLIO
=======================

HOW TO OPEN
1. Double-click index.html.
2. The website will open in your normal web browser.
3. No installation or terminal commands are required.

HOW TO EDIT
- Open index.html in any text editor to change words, sections, links, or project cards.
- Open style.css to change colors, spacing, fonts, and layout.
- Open script.js to change the mobile menu, tabs, or contact form behavior.
- Put new photos inside the images folder, then reference them like:
  images/my-project.jpg

HOW TO ADD A PROJECT
1. Open index.html.
2. Search for: EDIT YOUR PROJECT COLLECTIONS BELOW
3. Copy one complete <article class="project-collection"> ... </article> block.
4. Paste it below another card.
5. Change the title, description, number, and tags.

IMPORTANT
- Keep index.html, style.css, script.js, and the images folder together.
- The contact form opens the visitor's email app. It does not require a server.
